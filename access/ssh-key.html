Create your SSH public key

One command makes two files. You keep the private key. You send the public key (the one ending in .pub). Pick your system.

Windows 10 / 11

  1. Press Windows key + R, type cmd, press Enter.
  2. Run the command below. Press Enter at every question to accept the default.
  3. Show your public key and attach that file to your email.
ssh-keygen -t ed25519
Command Prompt · example
C:\Users\you> ssh-keygen -t ed25519
Generating public/private ed25519 key pair.
Enter file in which to save the key (C:\Users\you/.ssh/id_ed25519): [Enter]
Enter passphrase (empty for no passphrase): [Enter, or type one]
Enter same passphrase again: [Enter]
Your public key has been saved in C:\Users\you/.ssh/id_ed25519.pub
(then a key fingerprint and a small random-art picture: that is normal)

C:\Users\you> type %USERPROFILE%\.ssh\id_ed25519.pub
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...kR2x you@laptop
type %USERPROFILE%\.ssh\id_ed25519.pub

File to send: C:\Users\<you>\.ssh\id_ed25519.pub

"ssh-keygen is not recognized"? Open Settings › Apps › Optional features, add OpenSSH Client, then reopen cmd.

Using PowerShell instead of cmd? Show the key with type $env:USERPROFILE\.ssh\id_ed25519.pub.

macOS

  1. Open Terminal (Finder › Applications › Utilities › Terminal, or Cmd+Space and type "Terminal").
  2. Run the command below. Press Enter at every question.
  3. Show your public key and attach that file to your email.
ssh-keygen -t ed25519
Terminal · example
you@mac ~ % ssh-keygen -t ed25519
Generating public/private ed25519 key pair.
Enter file in which to save the key (/Users/you/.ssh/id_ed25519): [Enter]
Enter passphrase (empty for no passphrase): [Enter, or type one]
Enter same passphrase again: [Enter]
Your public key has been saved in /Users/you/.ssh/id_ed25519.pub
(then a key fingerprint and a small random-art picture: that is normal)

you@mac ~ % cat ~/.ssh/id_ed25519.pub
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...kR2x you@mac
cat ~/.ssh/id_ed25519.pub

File to send: ~/.ssh/id_ed25519.pub. The .ssh folder is hidden in Finder; press Cmd+Shift+. to show it, or run open ~/.ssh.

Linux

  1. Open a terminal (Ctrl+Alt+T on Ubuntu).
  2. Run the command below. Press Enter at every question.
  3. Show your public key and attach that file to your email.
ssh-keygen -t ed25519
Terminal · example
you@laptop:~$ ssh-keygen -t ed25519
Generating public/private ed25519 key pair.
Enter file in which to save the key (/home/you/.ssh/id_ed25519): [Enter]
Enter passphrase (empty for no passphrase): [Enter, or type one]
Enter same passphrase again: [Enter]
Your public key has been saved in /home/you/.ssh/id_ed25519.pub
(then a key fingerprint and a small random-art picture: that is normal)

you@laptop:~$ cat ~/.ssh/id_ed25519.pub
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...kR2x you@laptop
cat ~/.ssh/id_ed25519.pub

File to send: ~/.ssh/id_ed25519.pub

If it asks Overwrite (y/n)?, you already have a key. Type n and send your existing id_ed25519.pub.
Never share your private key (the file without .pub). Anyone who has it can log in as you.
