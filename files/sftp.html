Upload & download with sftp

Run sftp from a terminal on your laptop, not on the HPC. put sends a file to the HPC. get brings a file back to your laptop.

Where to keep files on the HPC

FolderPut here
/home/<username>Code, scripts, conda environments
/scratch/<username>Datasets, checkpoints, results: anything large

Connect

sftp <username>@hpc.bits-hyderabad.ac.in

The prompt changes to sftp>. Uploads come from the laptop folder you opened the terminal in.

Example

your laptop · sftp
you@laptop:~/project$ sftp <username>@hpc.bits-hyderabad.ac.in
Connected to hpc.bits-hyderabad.ac.in.
sftp> cd /scratch/<username>
sftp> put dataset.zip
Uploading dataset.zip to /scratch/<username>/dataset.zip
dataset.zip                         100% 2150MB  48.3MB/s   00:44
sftp> put -r code                       # -r = a whole folder
sftp> get runs/best.pt
Fetching /scratch/<username>/runs/best.pt to best.pt
best.pt                             100%   88MB  52.0MB/s   00:01
sftp> exit

sftp commands

CommandWhat it does
put fileUpload a file (laptop → HPC)
put -r folderUpload a folder
get fileDownload a file (HPC → laptop)
get -r folderDownload a folder
ls · cd · pwdList / change / show folder on the HPC
lls · lcd · lpwdThe same on your laptop (l = local)
mkdir nameMake a folder on the HPC
exitQuit sftp
