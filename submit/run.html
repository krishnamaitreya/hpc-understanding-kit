Submit it and read the output

Log in, go to your project folder, save the script, and run sbatch.

1 · Save the script on the HPC

cd /scratch/$USER/myproject
nano job.sh

Paste the script from the previous page. Press Ctrl+O, then Enter to save, then Ctrl+X to exit.

Or write job.sh on your laptop and upload it with put job.sh in sftp.

2 · Submit

sbatch job.sh
HPC · example
[<username>@hpc01 myproject]$ sbatch job.sh
Submitted batch job 482913

The number is your job ID. You need it to check or cancel the job.

3 · Read the output

Slurm writes two files in the same folder as job.sh, named after your job name and job ID:

FileContainsRead it with
my_job_482913.outEverything your program prints: progress, losses, resultstail -f my_job_482913.out
my_job_482913.errErrors, Python tracebacks and warningscat my_job_482913.err
HPC · example
[<username>@hpc01 myproject]$ tail -f my_job_482913.out
Epoch 1/100  loss 1.182  val_acc 0.412
Epoch 2/100  loss 1.104  val_acc 0.448
# new lines appear as the job runs. Ctrl+C stops watching; the job keeps running.

Job ended quickly? Open the .err file first. The reason is almost always there.
